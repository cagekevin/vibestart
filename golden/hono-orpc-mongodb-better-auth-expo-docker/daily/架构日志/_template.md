## 二、探债

**先列覆盖地图**：本轮查了哪些域（入口与配置、状态与缓存、持久化与迁移、协议与插件、进程与资源、包与示例、脚本、测试、文档），**哪些没查、为什么**。没写「没查什么」的体检等于没做。

**再按九个透镜找候选**：休眠契约 / 分裂真相 / 无主灵活性 / 中转层 / 并行状态机 / 边界表演 / 自造基础设施 / 支撑拖拽 / 功能化石。

每条写：位置 → 现象 → 判据（ADR / 规范条款）→ **证据级别**（味道 / 静态线索 / 消费者地图 / 契约证据 / 行为证据）→ 债号（`TD-<NN>-<序号>`）。

**只有到「契约证据」才登记为「该删」；前两级登记为「待证」。** 每条另写两格：

- **Proof**：能暴露「删错了」的最小检查。
- **净效果**：删掉的概念 − 新增的迁移机制。为负就写「不删」。

**终态检查**：这段代码结束之后，还有没有写入、回调、资源占用？指名哪项检查能发现迟到副作用。

**生命周期四问**：每个 flag / promise / 队列 / 哨兵都要回答 —— 谁写、谁读、代表哪个状态转移、终态之后还能不能动。答不全就是没想清。

## 三、结论

- 已收口：改了什么，旧入口是否删净。
- 未收口：为什么停，下一步是什么。
